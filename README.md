# Bari Vara

An offline-first rent manager for small Bangladeshi landlords.

## Foundation

- Package identifier: `com.nextgenai.barivara`
- Platforms: Android (min SDK 24) and iOS (min version 15)
- UI orientation: portrait
- Architecture: `app`, `core`, `features`, and `shared`
- State and DI: Riverpod
- Planned local persistence: SQLite with Drift
